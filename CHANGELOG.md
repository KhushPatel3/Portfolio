## Versioning

This project follows Semantic Versioning principles:

- **MAJOR:** Major changes that break compatibility or substantially change the system.
- **MINOR:** New features or significant functionality.
- **PATCH:** Bug fixes and small improvements.

During early development, versions use the `0.x.x` format. Alpha labels identify unfinished development milestones.
