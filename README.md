# Personal Investment Tracker

A personal investment tracking dashboard designed to consolidate investment data, monitor portfolio performance and provide a clear overview of holdings across multiple investment platforms.

> **Status:** Active development  
> **Current version:** v0.1.0-alpha.1  
> **Stability:** Experimental. Not intended for production use.

## Objectives

The project aims to provide:

- A consolidated view of investments across multiple platforms.
- Portfolio valuation in NZD.
- Holdings, transactions and dividend tracking.
- Historical portfolio performance.
- Region, sector and industry allocation.
- Market status and currency exchange information.
- Automated data updates.
- A simple and accessible dashboard.

The tracker is intended for personal use. Investment data and any associated credentials should be handled securely.

Never commit API keys, access tokens, private deployment credentials or sensitive financial information to this repository.
